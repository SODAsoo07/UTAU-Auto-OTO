UTAU Auto OTO - VM 회귀 테스트 체크리스트

권장 환경
- Hyper-V 또는 VirtualBox
- Windows 10/11 새 VM
- 스냅샷 이름 예시: `clean-win-before-auto-oto`

기본 원칙
- 매 테스트는 같은 클린 스냅샷에서 시작
- 실패하면 로그와 스크린샷을 같이 남김
- 수정 후 같은 체크리스트를 반복

공통 준비
- 배포 zip
- 한국어 샘플 1개
- 일본어 샘플 1개
- TextGrid 있는 샘플 1개
- TextGrid 없는 샘플 1개

체크리스트

[A] 첫 실행
- [ ] 배포 zip 압축 해제
- [ ] `UTAU_Auto_OTO.exe` 실행 성공
- [ ] 시작 직후 치명적 오류 팝업 없음
- [ ] `logs` 폴더 생성

[B] TextGrid 있는 샘플
- [ ] WAV 폴더 선택
- [ ] `4. OTO.ini 생성` 성공
- [ ] `oto.ini` 생성
- [ ] validation report 생성
- [ ] 불필요한 MFA 설치 요구 없음

[C] TextGrid 없는 샘플 - 한국어
- [ ] `3. 음성 정렬` 클릭
- [ ] MFA 자동 설치 시작
- [ ] 설치 로그가 진행 상황을 설명함
- [ ] 한국어 모델 다운로드 성공
- [ ] 정렬 성공
- [ ] 이후 OTO 생성 성공

[D] TextGrid 없는 샘플 - 일본어
- [ ] `3. 음성 정렬` 클릭
- [ ] MFA 자동 설치 또는 기존 MFA 재사용
- [ ] 일본어 모델 다운로드 성공
- [ ] 정렬 성공
- [ ] 이후 OTO 생성 성공

[E] 초보자 UX
- [ ] 기본 화면에서 SOFA가 과하게 노출되지 않음
- [ ] `MFA`가 기본값으로 유지됨
- [ ] 버튼명만 보고도 다음 행동을 이해 가능
- [ ] 실패 시 메시지가 해결 방향을 제시함

[F] 경로/권한
- [ ] 비 ASCII 경로에서 실행 확인
- [ ] 관리자 권한 없이 실행 확인
- [ ] 재실행 시 기존 MFA 환경 재사용

[G] 실패 시 안내 품질
- [ ] 네트워크 끊김 시 이해 가능한 오류 메시지
- [ ] 모델 다운로드 실패 시 재시도 방향 안내
- [ ] 권한 문제 시 안내 문구 확인
- [ ] 로그 파일 위치 안내가 충분함

권장 추가 시나리오
- [ ] 느린 네트워크
- [ ] Defender 기본 설정
- [ ] 설치 중 앱 재실행
- [ ] 이미 일부 파일이 남아 있는 반쯤 설치된 상태
