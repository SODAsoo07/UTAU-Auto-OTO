UTAU Auto OTO - Windows Sandbox 테스트 절차

목적
- 완전 클린 Windows 환경에서 프로그램이 실제로 실행되는지 확인
- 초보자 기준으로 설치/정렬/OTO 생성 흐름이 자연스러운지 확인

사전 준비
1. 배포 폴더 `UTAU_Auto_OTO_Release`를 zip으로 묶습니다.
2. 테스트용 음원 폴더를 하나 준비합니다.
3. 가능하면 아래 2종을 모두 준비합니다.
   - TextGrid가 이미 있는 샘플
   - TextGrid가 없는 샘플

Sandbox 실행 전 체크
1. Windows 기능에서 `Windows Sandbox`가 켜져 있는지 확인
2. 인터넷 연결이 가능한지 확인
3. 배포 zip과 테스트 음원 폴더를 바탕화면 등에 두기

테스트 절차
1. `Windows Sandbox`를 실행합니다.
2. 배포 zip을 Sandbox 안으로 복사합니다.
3. zip을 풉니다.
4. `UTAU_Auto_OTO.exe`를 실행합니다.

1차 확인: 프로그램 기동
1. 실행 직후 앱이 정상적으로 열리는지 확인
2. DLL 누락, Python 누락, customtkinter 누락 같은 시작 오류가 없는지 확인
3. `logs` 폴더가 생성되는지 확인

2차 확인: TextGrid가 이미 있는 경우
1. TextGrid 포함 샘플 음원을 Sandbox 안으로 복사합니다.
2. 앱에서 WAV 폴더를 선택합니다.
3. `4. OTO.ini 생성`만 실행합니다.
4. 확인 항목
   - OTO가 생성되는지
   - validation report가 생성되는지
   - 정렬 엔진 설치 없이도 문제없이 끝나는지

3차 확인: TextGrid가 없는 경우
1. TextGrid 없는 샘플 음원을 Sandbox 안으로 복사합니다.
2. 앱에서 WAV 폴더를 선택합니다.
3. `3. 음성 정렬`을 클릭합니다.
4. 확인 항목
   - MFA가 자동 설치되는지
   - 설치 로그가 이해 가능한지
   - 언어 모델 다운로드가 자동으로 되는지
   - 설치 완료 후 정렬까지 이어지는지
   - 이후 `4. OTO.ini 생성`까지 정상 진행되는지

한국어 추가 확인
1. 한국어 샘플에서 MFA 설치 중 `eunjeon`, `jamo` 관련 오류가 없는지 확인
2. Visual C++ 필요 시 안내 메시지가 알아보기 쉽게 뜨는지 확인

일본어 추가 확인
1. 일본어 샘플에서 일본어 모델 다운로드가 자동으로 되는지 확인
2. 일본어 alias 생성/기본 OTO 생성이 정상인지 확인

실패 시 기록할 것
1. 어떤 버튼을 눌렀는지
2. 어느 단계에서 멈췄는지
3. 화면 메시지
4. `logs` 폴더 안 최신 로그 파일
5. 가능하면 스크린샷

합격 기준
1. 앱이 설치 없이 실행된다
2. TextGrid가 있으면 바로 OTO 생성이 된다
3. TextGrid가 없으면 `3. 음성 정렬` 한 번으로 MFA 설치 + 정렬이 이어진다
4. 오류가 나더라도 사용자가 다음 행동을 이해할 수 있다
