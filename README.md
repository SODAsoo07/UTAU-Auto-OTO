## 개발 현황 (2026-03-28 동기화)

- 한국어 `C+V`는 Preview 채널에서만 노출/실행됩니다.
- 일본어 `CVVC` 매핑/보정 로직 개선이 반영되었습니다.
- 음절 탐지/경계 보정 관련 코어 로직(한국어/일본어)이 백포트되었습니다.
- 접미사 파싱 강화가 반영되었습니다(영문/숫자 접미사, 한자 접미사 처리, 호흡성 한자 예외).
- CTC/MFA 생성 파이프라인 관련 코어 변경이 반영되었습니다.

세부 현황과 ML 관련 메모는 `ml/README.md`를 기준 문서로 유지합니다.
