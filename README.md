우타우 보이스뱅크의 자동 원음설정을 위한 툴입니다. 현재 한국어와 일본어를 지원합니다.

A tool for automatic Otoing in Utau VoiceBank. It currently supports Korean and Japanese.

### 지원 형식:
한국어 Korean
- CV (단음/연단음)
- CVC
- CVVC
- VCV (한연음)

일본어 Japanese
- CV (단음/연단음)
- CVVC
- VCV (연속음)
