# AutoOTO v3
UTAU/OpenUtau 보이스뱅크의 녹음 파일(WAV)을 분석해서 원음 설정 파일(`oto.ini`)을 자동으로 만들어 주는 프로그램입니다. 현재 윈도우만 지원합니다.

>**이 프로그램은 AI를 이용하여 제작되었고, 본인이 코드 일부 수정 및 검수를 완료했습니다.**

이 프로그램은 처음부터 완벽한 oto를 만들어 주는 게 아니라, **자동으로 초안을 만든 뒤 직접 고치는 것**을 염두에 두고 만들었습니다. 생성된 oto는 틀릴 수 있으니 다시 한 번 확인해 주세요.

버그, 취약점, 어쨌든 프로그램이 뜻대로 동작하지 않는 경우를 발견하신다면 꼭 제보 부탁드립니다!

----
## 지원 형식

| 언어 | 형식 |
|---|---|
| 한국어 | CV, CVC, CVVC, VCV |
| 일본어 | CV, CVVC, VCV |

- 형식을 잘 모르겠다면 **자동 감지**로 두셔도 됩니다. 기존 oto.ini의 에일리어스, WAV 파일 이름, 폴더 이름(`KO CVVC`, `JP_VCV` 같은)을 보고 형식을 추측합니다.
- 언어는 자동으로 감지되지 않으니 직접 골라 주세요.
----
## 준비물
- 64비트 윈도우 10/11
- 녹음이 끝난 보이스뱅크 폴더 (WAV 파일들)
- 기존 `oto.ini` (선택) — 없어도 됩니다. 있을 시 첨부하면 에일리어스 목록을 그대로 사용합니다.

**프로그램이 아예 실행되지 않는다면 Microsoft Visual C++ 2015-2022 (x64) 런타임을 설치해 주세요.**
마이크로소프트 공식 다운로드 링크: https://aka.ms/vs/17/release/vc_redist.x64.exe

## 설치
1. 이 저장소 오른쪽의 [Releases](https://github.com/SODAsoo07/UTAU-Auto-OTO/releases)에서 최신 버전 zip 파일을 받습니다.
2. 원하는 곳에 압축을 풉니다. (바탕화면, 문서 폴더 등 아무 데나 괜찮습니다)
3. 압축을 푼 폴더 안의 실행 파일(exe)을 더블클릭하면 프로그램이 열립니다.

별도 설치 과정은 없습니다. 지울 때는 폴더째로 삭제하시면 됩니다.

----
## 사용 방법
프로그램을 켜면 `생성`, `결과`, `로그`, `크레딧` 탭이 보입니다. 대부분의 작업은 `생성` 탭에서 끝납니다.

### 1. 폴더 고르기
- **보이스뱅크 폴더**: `찾아보기`를 눌러 WAV 파일이 들어 있는 폴더를 고릅니다.
- **기존 oto.ini (선택)**: 이미 만들어 둔 oto.ini가 있다면 골라 주세요.
  - 기존 oto.ini는 **어떤 에일리어스를 만들지 참고하는 용도로만** 쓰고, 안에 적힌 타이밍 값은 쓰지 않습니다. 타이밍은 전부 녹음을 듣고(분석해서) 새로 잡습니다.
  - 없으면 WAV 파일 이름을 보고 형식에 맞는 에일리어스(`- ka`, `ka`, `a k`, `a ka` 등)를 알아서 만듭니다.
- **출력 폴더**: 새 oto.ini가 저장될 폴더입니다. 기본은 보이스뱅크와 다른 별도 폴더에 저장합니다.

> 보이스뱅크 폴더에 바로 저장하고 싶다면 `기존 oto.ini 덮어쓰기 허용`을 켜 주세요. 원래 있던 oto.ini는 날짜·시간이 붙은 `.bak` 파일로 백업된 뒤 교체됩니다.

### 2. 하위 폴더가 있는 경우 (음계별 폴더 등)
`A3`, `C4`처럼 폴더가 여러 개로 나뉜 보이스뱅크라면 아래 둘 중 하나를 켜 주세요. (둘은 동시에 켤 수 없습니다)
- **하위 폴더 포함 (한 번에 처리)**: 모든 폴더를 한꺼번에 처리하고, 폴더마다 oto.ini를 나눠서 저장합니다.
- **하위 폴더별 일괄 생성**: WAV가 있는 폴더마다 따로 형식을 감지해서 각각 만듭니다. 생성 전에 폴더 목록이 뜨니, 만들 폴더만 체크하고 `생성`을 누르면 됩니다. 한 폴더가 실패해도 나머지는 계속 진행됩니다.

### 3. 언어·포맷 고르기
- **언어**: 한국어 / 일본어 중 직접 고릅니다.
- **포맷**: `자동 감지`(추천) 또는 CV / CVC / CVVC / VCV 중에서 고릅니다. 자동 감지를 고르면 아래에 감지된 형식과 근거가 표시됩니다. 감지 결과가 틀렸거나 "알 수 없음"으로 나오면 직접 골라 주세요.

**포맷이 실제 녹음과 다르면 에일리어스가 엉뚱한 음절에 붙거나 타이밍이 크게 틀어집니다. 꼭 확인해 주세요!**

### 4. 생성하기
`실행` 칸의 버튼을 순서대로 누르면 됩니다.

| 버튼 | 하는 일 |
|---|---|
| 입력 검사 | 생성 전에 WAV 개수, 에일리어스 연결 상태, 감지된 형식 등을 미리 확인합니다. |
| OTO 생성 | 실제로 oto.ini를 만듭니다. 뱅크 크기에 따라 몇 분 정도 걸릴 수 있어요. |
| 출력 검증 | 만들어진 oto.ini에 값이 이상한 줄이 없는지 검사합니다. |
| 출력 폴더 열기 | 결과가 저장된 폴더를 엽니다. |

진행 상황은 `로그` 탭에서 볼 수 있고, 끝나면 `결과` 탭에 요약이 표시됩니다.

### 5. UTAU/OpenUtau에서 확인하기
만들어진 `oto.ini`를 보이스뱅크 폴더에 넣고(덮어쓰기를 켰다면 이미 들어가 있습니다) UTAU/OpenUtau에서 불러와 여러 음을 직접 불러 보세요. 어색한 부분은 UTAU의 원음 설정 화면이나 setParam, vLabeler 같은 툴로 고쳐 주시면 됩니다.

## 결과 파일 설명
출력 폴더에는 아래 파일들이 생깁니다. 보통은 `oto.ini`만 쓰시면 됩니다.

| 파일 | 설명 |
|---|---|
| `oto.ini` | 전체 결과. 실제로 사용하는 파일입니다. |
| `oto.clean.ini` | 프로그램이 비교적 자신 있는 줄만 모은 파일 |
| `oto.review.ini` | 프로그램이 확신하지 못한 줄만 모은 파일. **틀렸다는 뜻이 아니라 "한번 들어봐 주세요"라는 뜻입니다.** 검수할 때 이 파일부터 보시면 편해요. |
| `generation_report.json` | 어떤 설정으로 만들었는지 적힌 보고서 (`결과` 탭의 `생성 보고서 열기`로 볼 수 있습니다) |
| `unmapped_aliases.csv` | 기존 oto.ini에 있었지만 녹음 파일과 연결하지 못해 빠진 에일리어스 목록 (해당하는 줄이 있을 때만 생깁니다) |

> 로그에 `[주의] 생성되지 않은 행 N개`가 뜨면, 기존 oto.ini의 에일리어스 중 일부가 WAV 파일 이름과 맞지 않아 빠졌다는 뜻입니다. 전체 목록은 `unmapped_aliases.csv`에서 확인할 수 있습니다.

## 추가 설정 (선택)
아래 기능들은 몰라도 사용에 지장이 없습니다. 결과를 내 취향에 맞추고 싶을 때만 건드려 주세요.

### 녹음 BPM (실험적)
가이드 BPM에 맞춰 녹음했다면 BPM을 입력하거나 `BPM 자동 추정`을 켤 수 있습니다. 음절 위치를 박자에 맞춰 잡는 데 참고합니다.
- 비워 두면 사용하지 않습니다. (기본값)
- 가이드 BGM 없이 자유롭게 녹음했다면 꺼 두세요.

### 고급 설정
`▶ 고급 설정`을 누르면 펼쳐집니다. **비워 둔 칸은 자동값을 씁니다.** 음절 위치는 그대로 두고 oto 줄의 모양만 바꿉니다.

| 항목 | 설명 |
|---|---|
| 인코딩 | oto.ini 저장 인코딩. 기본(`preserve`)은 기존 oto.ini와 같게 맞춥니다. 일본어 UTAU에서 글자가 깨지면 `cp932`(`shift_jis`), 한국어 UTAU라면 `cp949`를 써 보세요. OpenUtau는 `utf-8`도 괜찮습니다. |
| VC 끝 위치 / '-' 선행발성 | VC와 끝음(`a -`) 줄의 기준점. 권장값 그대로 두시면 됩니다. |
| CV/VC/VCV 오버랩 비율 | 오버랩을 선행발성의 몇 배로 할지 (0~1) |
| CV/VC/VCV 선행발성 이동 | 선행발성을 앞뒤로 옮깁니다. ms 단위, `+`면 늦게 |
| 고정 범위 연장 | 고정 범위(자음부)를 ms만큼 늘립니다. |
| 오른쪽 블랭크 여유 | 끝부분 여유를 ms만큼 더 둡니다. |

자주 쓰는 설정은 `프리셋 저장`으로 저장해 두고 `프리셋 불러오기`로 다시 쓸 수 있습니다. 헷갈리면 `기본값으로`를 눌러 되돌리세요.

## 문제 해결

### 프로그램이 실행되지 않아요
- 위의 Visual C++ 런타임을 설치했는지 확인해 주세요.
- 압축을 완전히 푼 뒤 실행했는지 확인해 주세요. (zip 안에서 바로 실행하면 안 됩니다)
- 실행 파일을 우클릭 → 관리자 권한으로 실행해 보세요.

### 결과가 크게 어긋나요
- **언어·포맷이 맞는지** 가장 먼저 확인해 주세요. 대부분의 큰 오류는 여기서 생깁니다.
- 녹음 앞뒤의 긴 무음, 잡음, 숨소리가 많으면 정확도가 떨어질 수 있습니다.
- 에일리어스가 옆 음절에 붙는(한 칸씩 밀리는) 경우가 종종 있습니다. 음성 분석의 한계라 아직 완전히 없애지 못했어요. `oto.review.ini`에 있는 줄부터 확인해 주세요.

### 일부 에일리어스가 안 만들어졌어요
- `unmapped_aliases.csv`를 확인해 주세요. 파일 이름과 에일리어스의 표기가 다르면(예: 파일은 `_ka_ki`, oto는 `ka'ki`) 대부분은 알아서 맞추지만 못 맞추는 경우도 있습니다.
- 구분자 없이 이어 쓴 한국어 VCV 파일 이름(`_gwagwagweo…` 같은)은 아직 음절을 나누지 못합니다. 다음 버전에서 고쳐 볼게요...

### 글자가 깨져요
- 고급 설정의 인코딩을 바꿔서 다시 생성해 보세요. (위 표 참고)

이것저것 다 해봤는데 안 된다: 로그(`로그` 탭의 `로그 복사`) 또는 오류 난 스크린샷과 함께 [Issues](https://github.com/SODAsoo07/UTAU-Auto-OTO/issues)나 트위터(@SODAsodasoo)로 제보해 주세요!
