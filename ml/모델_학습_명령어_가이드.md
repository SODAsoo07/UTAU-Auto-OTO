## 현재 기본 정책

현재 코드 기준 기본 정책은 아래와 같다.

- `pseudo label`: 기본 `OFF`
- `selector default ON`: `korean/cv`, `korean/cvc`
- `selector default OFF`: 그 외 형식
- `CV` 형식은 한국어/일본어 모두 family 분리를 기본으로 하지 않는다
- family 분리 기본 대상: `korean/cvc`, `korean/cvvc`, `japanese/cvvc`

- `japanese/cv`: `0.40`

## 한 줄 요약

- `dataset_stage`는 폴더다.
- `train_oto_ml_model.py --dataset`은 CSV다.
- 지금은 `pseudo label OFF`, `selector 보수 운용`, `CVVC/CVC는 family 분리 학습`이 기본 전략이다.

## 권장 family 분리 정책

- `korean/cv`: 분리하지 않음
- `japanese/cv`: 분리하지 않음
- `korean/cvc`: `cv`, `bridge` 분리
- `korean/cvvc`: `cv`, `bridge` 분리
- `japanese/cvvc`: `cv`, `bridge` 분리
- `vcv`: 현재는 공용 유지

## 권장 학습 조합

### 1. 한국어 CV / 일본어 CV
- family 분리 없이 공용 모델로 학습

### 2. 한국어 CVC
- `cv` family 모델 1개
- `bridge` family 모델 1개

### 3. 한국어 CVVC
- `cv` family 모델 1개
- `bridge` family 모델 1개

### 4. 일본어 CVVC
- `cv` family 모델 1개
- `bridge` family 모델 1개
- `japanese/cvvc`? `cv` family는 런타임에서 `delta`를 기본 비활성화하고 selector/guard 중심으로 운용

### 실행 원칙
- family 분리 대상이 아닌 `CV`는 `--alias-family` 없이 학습
- family 분리 대상은 `--alias-family cv`, `--alias-family bridge`로 각각 학습
- 예시 명령은 본 문서의 family 분리 학습 섹션을 그대로 사용
