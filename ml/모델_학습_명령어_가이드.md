## 12. 현재 운용 권장

### 한국어 CV

- `delta`: 사용
- `selector`: 사용
- family 분리 불필요

### 한국어 CVC

- `delta`: 사용
- `selector`: 사용
- `cv`, `bridge` 분리 권장

### 한국어 CVVC

- `delta`: 사용
- `selector`: 기본 `OFF`
- `cv`, `bridge` 분리 권장

### 한국어 VCV

- `delta`: 사용
- `selector`: 기본 `OFF`

### 일본어 CV

- `delta`: 사용
- `selector`: 기본 `OFF`
- family 분리 불필요

### 일본어 CVVC

- `delta`: 사용
- `selector`: 기본 `ON`
- `cv`, `bridge` 분리 권장
- `cv family`는 runtime에서 `delta off + selector/guard` 정책 유지

### 일본어 VCV

- `delta`: 사용
- `selector`: `OFF`

## 13. 주의사항

1. `train_oto_ml_model.py --dataset`은 폴더가 아니라 CSV 파일입니다.
2. `ML_models`는 이제 런타임이 자동 탐색합니다.
3. `manual oto`를 수정했거나 `TextGrid`가 바뀌었다면 `collect`부터 다시 해야 합니다.
4. 정책만 바뀌고 데이터가 그대로면 보통 재학습만 하면 됩니다.
