## 1. 설정 파일 점검
### 확인할 것
- 경로는 가능하면 YAML에서 **작은따옴표**로 감싼다.
  - 예: `'C:\Users\...\Singer\HARU'`
- Windows 경로를 큰따옴표로 쓰면 `\S` 같은 구간이 escape로 해석되어 YAML 에러가 날 수 있다.
- 폴더명이 실제 디스크 경로와 일치하는지 확인한다.
- 형식 분류가 맞는지 확인한다.
  - 예: `korean.cvc` / `korean.cvvc`
  - 예: `japanese.vcv` / `japanese.cvvc`

## 6. PyTorch dataset build + train
PyTorch는 **기존 torch dataset shard를 재사용하지 않고** 다시 build한다.

### 한국어 분리 task 순차 실행
```powershell
python ml\scripts\run_oto_torch_batch.py --tasks korean_bridge_cvvc_vv korean_bridge_cvvc_vc korean_bridge_cvc_vc
```

### 일본어 분리 task 순차 실행
```powershell
python ml\scripts\run_oto_torch_batch.py --tasks japanese_bridge_vcv_vv japanese_bridge_vcv_vc japanese_bridge_vcv_vcv japanese_bridge_vcv_cv_head japanese_bridge_cvvc_vv japanese_bridge_cvvc_vc japanese_bridge_cvvc_cv_head
```

### 전체 기본 순차 실행
```powershell
python ml\scripts\run_oto_torch_batch.py
```

### 주의: 기본 실행 범위
- `run_oto_torch_batch.py`의 기본 실행은 현재 **한국어 3개 태스크**만 포함한다.
  - `korean_bridge_cvvc_vv`
  - `korean_bridge_cvvc_vc`
  - `korean_bridge_cvc_vc`
- 일본어 태스크까지 한 번에 돌리려면 `--tasks`를 명시한다.
- 데이터가 너무 적은 태스크는 기본적으로 자동 스킵된다(`min_rows` 기준).
  - 강제 실행하려면 `--allow-tiny`를 사용한다.
- 학습 중 `valid_score` 정체 시 `ReduceLROnPlateau`로 LR이 자동 감쇠된다.
  - 기본값: `factor=0.5`, `patience=1`, `min_lr=1e-5`, `threshold=0.5`
  - 필요 시 `--lr-reduce-*` 인자로 조정 가능

### 전체 태스크(한국어+일본어) 순차 실행 예시
```powershell
python ml\scripts\run_oto_torch_batch.py --tasks korean_bridge_cvvc_vv korean_bridge_cvvc_vc korean_bridge_cvc_vc japanese_bridge_vcv_vv japanese_bridge_vcv_vc japanese_bridge_vcv_vcv japanese_bridge_vcv_cv_head japanese_bridge_cvvc_vv japanese_bridge_cvvc_vc japanese_bridge_cvvc_cv_head
```
