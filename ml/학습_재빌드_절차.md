## 목적
`ml/configs/training_data_roots.yaml`에 새 보이스뱅크 경로를 추가했을 때,
스테이징부터 LightGBM/PyTorch 학습까지 다시 돌리는 순서를 정리한다.

## 전제
- 작업 루트: `C:\Users\oyh57\SODAsoo1\Devs\UTAU_Auto_OTO_v3\Auto_OTO`
- 설정 파일: `ml/configs/training_data_roots.yaml`
- 새 데이터를 추가한 뒤에는 **기존 torch dataset shard를 재사용하지 않는다**.
- 기존 학습용 CSV도 새 데이터 반영을 위해 다시 빌드하는 것이 원칙이다.

## 1. 설정 파일 점검
### 확인할 것
- 경로는 가능하면 YAML에서 **작은따옴표**로 감싼다.
  - 예: `'C:\Users\...\Singer\HARU'`
- Windows 경로를 큰따옴표로 쓰면 `\S` 같은 구간이 escape로 해석되어 YAML 에러가 날 수 있다.
- 폴더명이 실제 디스크 경로와 일치하는지 확인한다.
- 형식 분류가 맞는지 확인한다.
  - 예: `korean.cvc` / `korean.cvvc`
  - 예: `japanese.vcv` / `japanese.cvvc`

## 6. PyTorch dataset build + train
PyTorch는 **기존 torch dataset shard를 재사용하지 않고** 다시 build한다.

### 한국어 분리 task 순차 실행


### 전체 기본 순차 실행
```powershell
python ml\scripts\run_oto_torch_batch.py
```

## 7. PyTorch 개별 실행 예시
### 한국어 CVVC VC sonorant

## 10. 권장 점검 포인트
### 데이터 추가 직후
- `training_data_roots.yaml` 경로 오타
- 형식 분류 오기입
- 특수 폴더(숨/breath, 무성 자음 전용 등) 포함 여부

### build 이후
- `ml_workspace\reports\training_build_results.json`
- `saved_rows == 0` 항목 존재 여부
- 형식별 `unique voicebanks` 수

### 학습 이후
- `eval_summary.json`
- 한국어: `offset`, `cutoff` 악화 여부
- 일본어: `VV`, `VC`, `VCV` 개선 여부
