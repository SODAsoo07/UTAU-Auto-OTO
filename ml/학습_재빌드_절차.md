# Auto_OTO 데이터 추가 및 재학습 절차

## 목적
`ml/configs/training_data_roots.yaml`에 새 보이스뱅크 경로를 추가했을 때,
스테이징부터 `LightGBM` 재학습과 런타임 반영까지 다시 돌리는 현재 표준 절차를 정리한다.

## 전제
- 작업 루트: `C:\Users\oyh57\SODAsoo1\Devs\UTAU_Auto_OTO_v3\Auto_OTO`
- 설정 파일: `ml/configs/training_data_roots.yaml`
- 새 데이터를 추가한 뒤에는 학습용 CSV를 다시 빌드하는 것을 원칙으로 한다.
- OTO 자동 생성 보정용 `PyTorch` 파이프라인은 제거되었으므로 이 문서는 `LightGBM`만 다룬다.

## 1. 설정 파일 점검
- 경로는 가능하면 YAML에서 작은따옴표로 감싼다.
- 폴더명이 실제 디스크 경로와 일치하는지 확인한다.
- 형식 분류가 맞는지 확인한다.
  - 예: `korean.cv`, `korean.cvc`, `korean.cvvc`
  - 예: `japanese.cv`, `japanese.vcv`, `japanese.cvvc`

## 2. 스테이징
원본 경로를 `Auto_OTO/dataset` 아래로 복사한다.

```powershell
cd C:\Users\oyh57\SODAsoo1\Devs\UTAU_Auto_OTO_v3\Auto_OTO
python ml\scripts\stage_training_sources.py
```

## 3. auto oto + TextGrid 준비
스테이징된 데이터에서 자동 OTO와 TextGrid를 준비한다.

```powershell
python ml\scripts\prepare_staged_auto_pairs.py
```

참고:
- 시간이 가장 오래 걸릴 수 있다.
- MFA/SOFA, auto oto, TextGrid 생성 상태에 따라 일부 폴더는 skip될 수 있다.

## 4. 학습용 CSV 재구축
학습 CSV를 다시 만든다.

```powershell
python ml\scripts\collect_oto_ml_training_data.py
```

기본 스캔 기준:
- 기본 동작은 `Auto_OTO/dataset` 스캔이다.
- 원본 루트를 직접 스캔하려면 `--use-config-roots`를 사용한다.

결과물 예시:
- `..\ml_workspace\datasets\korean\dataset_korean_cv.csv`
- `..\ml_workspace\datasets\korean\dataset_korean_cvc.csv`
- `..\ml_workspace\datasets\korean\dataset_korean_cvvc.csv`
- `..\ml_workspace\datasets\korean\dataset_korean_general.csv`
- `..\ml_workspace\datasets\japanese\dataset_japanese_cv.csv`
- `..\ml_workspace\datasets\japanese\dataset_japanese_cvvc.csv`
- `..\ml_workspace\datasets\japanese\dataset_japanese_vcv.csv`
- `..\ml_workspace\datasets\japanese\dataset_japanese_general.csv`

## 5. LightGBM 재학습
형식별로 다시 학습한다.

예시: 한국어 `CVVC`

```powershell
python ml\scripts\train_oto_ml_model.py --lang korean --format cvvc --dataset ..\ml_workspace\datasets\korean\dataset_korean_cvvc.csv --out-dir assets\models\oto_ml\korean\cvvc\profile_run_new
```

예시: 일본어 `VCV`

```powershell
python ml\scripts\train_oto_ml_model.py --lang japanese --format vcv --dataset ..\ml_workspace\datasets\japanese\dataset_japanese_vcv.csv --out-dir assets\models\oto_ml\japanese\vcv\profile_run_new
```

의사라벨 가중치 옵션:
- `--use-pseudo-labels / --no-use-pseudo-labels`
- `--pseudo-weight-high` 기본 `0.7`
- `--pseudo-weight-mid` 기본 `0.4`

예시:

```powershell
python ml\scripts\train_oto_ml_model.py --lang korean --format cvvc --dataset ..\ml_workspace\datasets\korean\dataset_korean_cvvc.csv --out-dir assets\models\oto_ml\korean\cvvc\profile_run_new --use-pseudo-labels --pseudo-weight-high 0.7 --pseudo-weight-mid 0.4
```

## 6. 평가

```powershell
python ml\scripts\evaluate_oto_ml_model.py --lang korean --format cvvc --dataset ..\ml_workspace\datasets\korean\dataset_korean_cvvc.csv --model-dir assets\models\oto_ml\korean\cvvc\profile_run_new
```

## 7. 번들 export

```powershell
python ml\scripts\export_oto_ml_bundle.py --bundle assets\models\oto_ml\korean\cvvc\profile_run_new --export-root ..\ml_workspace\exports\model_bundles --zip
```

## 8. 런타임 설치
- export된 폴더 또는 zip을 설치 스크립트에 넣는다.
- 기본 설치 위치: `models_installed\oto_ml\{language}\{format}\v1`
- 런타임 로더는 같은 언어/형식에서 `models_installed`를 `assets`보다 우선 사용한다.

```powershell
python ml\scripts\install_oto_ml_bundle.py --bundle ..\ml_workspace\exports\model_bundles\korean_cvvc_profile_run_new.zip
```

## 9. 앱에서 적용 확인
1. 앱 실행
2. OTO 생성 탭에서 `LightGBM 보정 적용` 체크
3. 테스트 보이스뱅크로 OTO 재생성
4. 로그에서 `[OTO-ML] 모델 로드` 경로가 `models_installed\oto_ml\...` 인지 확인

## 10. 롤백
- 설치 전 `models_installed\oto_ml`를 백업해 두는 것이 가장 빠르다.
- 문제가 있으면 백업 복원 또는 다른 번들을 다시 install하면 된다.

## 11. 권장 점검 포인트
- 데이터 추가 직후:
  - `training_data_roots.yaml` 경로 오타
  - 형식 분류 오기입
  - 특수 폴더 포함 여부
- build 이후:
  - `ml_workspace\reports\training_build_results.json`
  - `saved_rows == 0` 항목 존재 여부
  - 형식별 `unique voicebanks` 수
- 학습 이후:
  - `eval_summary.json`
  - 한국어: `offset`, `cutoff` 악화 여부
  - 일본어: `VV`, `VC`, `VCV` 개선 여부
