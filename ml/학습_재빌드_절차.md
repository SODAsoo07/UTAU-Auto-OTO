  - 예: `japanese.vcv` / `japanese.cvvc`

## 6. PyTorch dataset build + train
PyTorch는 **기존 torch dataset shard를 재사용하지 않고** 다시 build한다.

### 한국어 분리 task 순차 실행
```powershell

```

### 일본어 분리 task 순차 실행
```powershell
python ml\scripts\run_oto_torch_batch.py --tasks japanese_bridge_vcv_vv japanese_bridge_vcv_vc japanese_bridge_vcv_vcv japanese_bridge_vcv_cv_head japanese_bridge_cvvc_vv japanese_bridge_cvvc_vc japanese_bridge_cvvc_cv_head
```

### 전체 기본 순차 실행
```powershell
python ml\scripts\run_oto_torch_batch.py
```

### 주의: 기본 실행 범위
- `run_oto_torch_batch.py`의 기본 실행은 현재 **한국어 3개 태스크**만 포함한다.
  - `korean_bridge_cvvc_vv`
  - `korean_bridge_cvvc_vc`
  - `korean_bridge_cvc_vc`
- 일본어 태스크까지 한 번에 돌리려면 `--tasks`를 명시한다.
- 데이터가 너무 적은 태스크는 기본적으로 자동 스킵된다(`min_rows` 기준).
  - 강제 실행하려면 `--allow-tiny`를 사용한다.
- 학습 중 `valid_score` 정체 시 `ReduceLROnPlateau`로 LR이 자동 감쇠된다.
  - 기본값: `factor=0.5`, `patience=1`, `min_lr=1e-5`, `threshold=0.5`
  - 필요 시 `--lr-reduce-*` 인자로 조정 가능
- 현재 PyTorch 학습 CLI는 기본적으로 CUDA를 요구한다(`--require-cuda` 기본 ON).
  - GPU가 없거나 CPU로만 시험하려면 `--no-require-cuda`를 명시한다.

### 전체 태스크(한국어+일본어) 순차 실행 예시
```powershell
python ml\scripts\run_oto_torch_batch.py --tasks korean_bridge_cvvc_vv korean_bridge_cvvc_vc korean_bridge_cvc_vc japanese_bridge_vcv_vv japanese_bridge_vcv_vc japanese_bridge_vcv_vcv japanese_bridge_vcv_cv_head japanese_bridge_cvvc_vv japanese_bridge_cvvc_vc japanese_bridge_cvvc_cv_head
```

## 10. LightGBM 재학습 결과물 실사용 반영 절차
LightGBM을 다시 학습한 뒤, 앱에서 실제로 쓰려면 `export -> install -> 앱 생성 테스트` 순서를 거친다.

### 10-1. 평가 통과한 학습 디렉터리 선정
- `eval_summary.json` 기준으로 사용할 학습 디렉터리를 먼저 확정한다.
- 예: `assets\models\oto_ml\korean\cvvc\profile_run_new`

### 10-2. 번들 내보내기(export)
```powershell
python ml\scripts\export_oto_ml_bundle.py --bundle assets\models\oto_ml\korean\cvvc\profile_run_new --export-root ..\ml_workspace\exports\model_bundles --zip
```

### 10-3. 런타임 설치(install)
- export된 **폴더 또는 zip**을 설치 스크립트에 넣는다.
- 설치 위치 기본값: `Auto_OTO\models_installed\oto_ml\{language}\{format}\v1`
- 런타임 로더는 같은 언어/형식에서 `models_installed`를 `assets`보다 우선 사용한다.

```powershell
python ml\scripts\install_oto_ml_bundle.py --bundle ..\ml_workspace\exports\model_bundles\korean_cvvc_profile_run_new.zip
```

### 10-4. 앱에서 적용 확인
1. 앱 실행
2. OTO 생성 탭에서 `LightGBM 보정 적용` 체크 ON
3. 테스트 보이스뱅크로 OTO 재생성
4. 로그에서 `[OTO-ML] 모델 로드` 경로가 `models_installed\oto_ml\...` 인지 확인

### 10-5. 롤백(되돌리기)
- 설치 전 `models_installed\oto_ml`를 백업해 두면 가장 빠르다.
- 문제가 있으면 백업 복원 또는 다른 번들을 다시 install하면 된다.

## 11. PyTorch 재학습 결과물 실사용 반영 절차
PyTorch는 현재 LightGBM처럼 전용 `install_oto_torch_bundle.py`가 없으므로,
실사용 반영은 `런타임 경로에 직접 배치` 방식으로 진행한다.

### 11-1. 런타임이 찾는 기본 경로
- `assets\models\oto_ml_pytorch\{language}\{task}\v1`
- 또는 우선 경로: `models_installed\oto_ml_pytorch\{language}\{task}\v1`

현재 기본 task 매핑:
- 한국어 CVVC: `bridge_cvvc`
- 한국어 CVC: `bridge_cvc`
- 일본어 VCV: `bridge_vcv`
- 일본어 CVVC: `bridge_cvvc`

### 11-2. 권장 방식(학습 출력 경로를 런타임 경로로 바로 지정)
예: 한국어 CVVC
```powershell
python ml\scripts\train_oto_torch_model.py --lang korean --task bridge_cvvc --dataset-dir ..\ml_workspace\torch_datasets\korean\korean_bridge_cvvc_vc --out-dir assets\models\oto_ml_pytorch\korean\bridge_cvvc\v1
```

### 11-3. 이미 다른 경로로 학습한 경우(수동 배치)
학습 결과 디렉터리(`model_meta.json`, `model.pt` 등 포함)를 아래 경로로 복사한다.

```powershell
mkdir models_installed\oto_ml_pytorch\korean\bridge_cvvc\v1 -Force
Copy-Item assets\models\oto_ml_pytorch\korean\korean_bridge_cvvc_vc\v1\* models_installed\oto_ml_pytorch\korean\bridge_cvvc\v1\ -Recurse -Force
```

### 11-4. export는 배포용(선택)
```powershell
python ml\scripts\export_oto_torch_bundle.py --model-dir assets\models\oto_ml_pytorch\korean\bridge_cvvc\v1 --out-dir ..\ml_workspace\exports\torch_bundles
```

### 11-5. 앱에서 적용 확인
1. 앱 실행
2. OTO 생성 탭에서 `PyTorch 브리지 보정 적용` 체크 ON
3. 테스트 보이스뱅크로 OTO 재생성
4. 로그에서 `[OTO-ML] 모델 로드 (pytorch): ...` 확인

### 11-6. 롤백(되돌리기)
- `models_installed\oto_ml_pytorch` 백업본을 복원하거나
- 문제 있는 폴더만 삭제하면 `assets` 경로 모델로 자동 폴백된다.

## 12. 권장 점검 포인트
### 데이터 추가 직후
- `training_data_roots.yaml` 경로 오타
- 형식 분류 오기입
- 특수 폴더(숨/breath, 무성 자음 전용 등) 포함 여부

### build 이후
- `ml_workspace\reports\training_build_results.json`
- `saved_rows == 0` 항목 존재 여부
- 형식별 `unique voicebanks` 수

### 학습 이후
- `eval_summary.json`
- 한국어: `offset`, `cutoff` 악화 여부
- 일본어: `VV`, `VC`, `VCV` 개선 여부

## 13. 한 줄 요약
새 데이터 추가 후에는 항상 아래 순서다.

1. `stage_training_sources.py`
2. `prepare_staged_auto_pairs.py`
3. `collect_oto_ml_training_data.py`

7. PyTorch 실사용 반영: 런타임 경로(`assets` 또는 `models_installed`)에 모델 디렉터리 배치
