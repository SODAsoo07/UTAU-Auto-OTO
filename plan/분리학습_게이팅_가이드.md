# 분리 학습 + 런타임 게이팅 가이드

이 문서는 **LightGBM과 coupled(rawmel) 모델을 따로 학습**한 뒤,
런타임에서 **게이팅/블렌딩으로 상호작용**하는 기본 운영 경로를 정리합니다.

## 1) 데이터셋 준비

```powershell
Set-Location "C:\Users\oyh57\SODAsoo1\Devs\UTAU_Auto_OTO_v3\Auto_OTO"
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"

# staging + prepare + dataset build
.\ml\scripts\run_coupled_mel_oto_training.ps1 -StageSources -PrepareAuto -BuildDatasetOnly
```

## 2) LightGBM 모델 학습

```powershell
python .\ml\scripts\train_oto_lightgbm_model.py `
  --lang korean `
  --format cvvc `
  --dataset ".\ml_workspace\datasets\korean\dataset_korean_cvvc_coupled.csv" `
  --out-dir ".\ML_models\korean\cvvc\v1_lightgbm" `
  --group-column voicebank_id `
  --min-mapping-confidence 0.40
```

## 3) coupled(rawmel) 모델 학습

```powershell
python .\ml\scripts\coupled\train.py `
  --lang korean `
  --format cvvc `
  --dataset ".\ml_workspace\datasets\korean\dataset_korean_cvvc_coupled.csv" `
  --out-dir ".\ML_models\korean\cvvc\v1_coupled" `
  --backend coupled_nn_v2_rawmel `
  --rawmel-cache "<rawmel_cache_dir>" `
  --group-column voicebank_id `
  --min-mapping-confidence 0.40 `
  --epochs 70 `
  --batch-size 192 `
  --learning-rate 0.001
```

## 4) 런타임 게이팅 설정

런타임은 **coupled가 primary**, **lightgbm이 fallback**일 때
`UTOA_ML_GATED_ENSEMBLE_ENABLE`로 게이팅/블렌딩을 수행합니다.

권장 환경 변수:

```
UTOA_ML_GATED_ENSEMBLE_ENABLE=1
UTOA_ML_COUPLED_ENABLE=1
UTOA_ML_ENSEMBLE_ENABLE=0   # ensemble v1을 쓰지 않을 때 명시적으로 꺼도 됨
UTOA_ML_COUPLED_MIN_CONF=0.55
```

모델 탐색 순서: `ml_workspace/models` → `models_installed` → `ML_models` → `assets/models`.

## 참고
- voicebank가 1개뿐이라도 학습은 가능하나, 일반화 성능 평가는 약합니다.
- voicebank가 여러 개인 경우 `group-column voicebank_id`가 안정적입니다.
